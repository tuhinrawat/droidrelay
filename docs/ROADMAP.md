# Roadmap

Built solo, one phase at a time. Each phase ends with something usable, and the
next phase starts only when the previous phase's pass criteria are met.

| Phase | Ships | Status |
|---|---|---|
| 0 · Risk checks | Throwaway spikes — see [PHASE0.md](PHASE0.md) | 🟡 In progress |
| 1 · Quick Share receiver | Free Mac App Store app (receive only) | ⬜ |
| 2 · Pairing + basics | Android companion, QR pairing, encryption, files, Find my phone, diagnostics | ⬜ |
| 3 · Notifications + reply | Menu bar panel, Control Center, reply, per-app mute | ⬜ |
| 4 · Payments → v1.0 | 7-day trial (₹0 IAP, starts at pairing, 1 phone), ₹699 unlock, Restore, post-trial lock (Quick Share stays free) | ⬜ |
| 5 · Delight + discovery | Clipboard, link handoff, Focus sync, Discover hub, dark mode | ⬜ |
| 6 · Multi-phone | ₹299 per extra phone (max 3), switcher, per-phone priority / mute / filters / quiet hours | ⬜ |
| 7 · KDE Connect compatibility | Pair via the KDE Connect Android app (clean-room, after legal sign-off) | ⬜ |
| 8 · v2 | Webcam, screen mirroring, USB, call alerts | ⬜ |
